# Specialist Roles

Roles are capabilities assigned to bounded work inside the shared lifecycle; they do not own workflow progression.

- Architect: models the whole, interfaces, constraints and dependencies; usually Grounding or Momentum.
- Researcher: gathers source-backed evidence and uncertainty; usually Grounding, sometimes Momentum or Mastery.
- Builder: creates and integrates the selected outcome during Momentum.
- Independent Reviewer: challenges the exact candidate during Mastery, separate from its author.
- Domain Specialist: supplies a bounded capability where the project requires it.
- Orchestrator: owns shared state, priority, task graph, dispatch, integration gates, permissions and learning.

A role assignment carries workflow identity, stage, revision, capability, expected output and permission boundary. A prompt contract is not proof of an independent running process.
