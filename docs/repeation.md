# Repetition — the Learning Principle

Repetition is not doing the same thing again. It is the deliberate regeneration of a better next cycle from the difference between intention and outcome.

At the end of a cycle:
1. Compare intended outcomes with observed results.
2. Separate verified facts from interpretation and assumption.
3. Identify which model, estimate, dependency, risk or acceptance criterion was wrong.
4. Preserve durable evidence and decisions.
5. Update the task graph and project adapter without duplicating canonical state.
6. Choose the next coherent increment from the revised reality.

Never retry blindly. After two failures against the same hypothesis, stop and investigate root cause. A retry requires a changed hypothesis, intervention or newly available evidence.

Learning should improve the system's calibration, not merely increase its accumulated notes.
